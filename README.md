# Expense_tracker
This Expense Tracker Project is a secure, multi-user financial management system designed to organize and monitor personal finances efficiently. It allows users to record daily expenses, track investments, manage money lending, store nominee details, and maintain asset records in one place. The platform features a robust login and sign-up system, ensuring personalized access for each user. With passkey-based protection, user data remains safe and private. Each user gets a customized dashboard that provides a clear overview of their financial activities, helping them make informed decisions, improve budgeting habits, and gain better control over their financial health in a structured and user-friendly environment.
